# 🌌 Neon Vibe Survivor | 霓虹星際生存者 (v3.0 Ultimate)
> **Vibe Coding 互動網頁遊戲作品** — 結合「即時視聽氛圍調頻（Vibe Tuner）」、「程序化合成音樂（Web Audio API）」與「Roguelite 彈幕生存」的單一檔案 Web App。

---


## 一、 專案發想與設計動機 (Concept & Motivation)

在本次 Vibe Coding 作業中，我希望打造的不只是一個靜態網頁或單純的計分小工具，而是一款真正具備**高沉浸感、流暢打擊感與視聽律動（Vibe）**的互動式彈幕生存網頁遊戲 **《Neon Vibe Survivor：霓虹星際生存者》**。

### 核心設計理念：
1. **真正的「Vibe」即時調頻體驗**：玩家可以隨時在遊戲頂部切換三種截然不同的視覺與音樂氛圍（**電馭霓虹 Cyber**、**落日微風 Lofi**、**駭客矩陣 Matrix**）。切換瞬間不僅畫布背景、網格、戰機與彈幕配色會即時轉換，連底層合成器的背景音樂音階（Scale）與波形也會同步改變。
2. **零外部素材依賴的單一檔案架構（Zero-Asset Single HTML）**：為了完全符合「單一 `index.html` 即可實際開啟操作」的要求，本作品不依賴任何外部圖片或 MP3 音檔。所有幾何戰機、霓虹光暈、爆炸粒子皆透過 `HTML5 Canvas 2D API` 即時運算繪製；所有射擊、爆炸、升級與背景音樂皆由 `Web Audio API` 即時合成。
3. **高重玩價值的 Roguelite 機制**：結合三大初始戰機、9 種可疊加的升級卡牌、隨機空投補給箱、黑洞宇宙異象與即時成就解鎖系統，讓每次遊玩都有不同的流派體驗。

## 二、 系統架構與技術規格 (Technical Specifications)

| 規格項目 | 技術選型與實作細節 |
| :--- | :--- |
| **檔案結構** | 單一 `index.html` 檔案（整合 HTML5 結構、CSS3 霓虹濾鏡動畫與原生 JavaScript ES6+ 遊戲引擎）。 |
| **UI 與排版框架** | 使用 **Tailwind CSS (CDN)** 搭配 **Orbitron / Noto Sans TC** 科幻字體與 **Font Awesome** 圖示，並加上復古 CRT 掃描線（Scanlines）視覺覆蓋層。 |
| **圖形渲染引擎** | 原生 **HTML5 Canvas 2D API**，支援高幀率（60 FPS `requestAnimationFrame`）動態星空、透視網格、陰影發光（Shadow Blur）、畫面震動（Screen Shake）與底部即時聲波律動頻譜。 |
| **音效與配樂引擎** | 自建 `VibeAudioEngine` 類別（基於原生 **Web Audio API**），透過振盪器（Oscillator）與增益節點（GainNode）即時合成射擊、爆炸、閃電、護盾破碎、時空緩速與三種主題的動態背景音序。 |
| **跨裝置操作支援** | 同時支援 **電腦鍵盤滑鼠**（WASD / 方向鍵移動、快捷鍵施放技能與選卡、自動/滑鼠瞄準切換）與 **行動裝置觸控拖曳**（響應式畫布自適應）。 |
| **資料持久化儲存** | 使用瀏覽器 `localStorage` 自動記錄玩家的 **歷史最高分（High Score）** 與 **已解鎖的星際成就徽章（Achievements）**。 |

## 三、 功能規格書 (Functional Specifications)

### 1. 頂部控制列與即時狀態儀表板 (HUD & Vibe Tuner)
* **即時數據顯示**：包含目前波數（Wave）、戰機等級（LV）、即時分數（Score）、連擊倍率（Combo）與歷史最高紀錄（Best）。
* **雙動態狀態條**：即時顯示生命值（HP Bar）、能量護盾層數徽章（Shield Badge）與升級經驗值進度條（EXP Bar）。
* **Vibe 主題調頻器**：
  * `⚡ 電馭霓虹 (Cyber)`：深藍紫底色、青藍與洋紅霓虹光暈、動感合成波音階。
  * `🌅 落日微風 (Lofi)`：暖紫暮色底色、夕陽橘與金黃彈幕、柔和正弦波音階。
  * `👾 駭客矩陣 (Matrix)`：深邃黑綠底色、螢光綠數位網格、緊湊數位脈衝音階。
* **輔助功能開關**：支援「自動瞄準 / 滑鼠瞄準」切換、「圖鑑與改版日誌 v3.0」彈窗、音效開關與遊戲暫停（`P` 鍵）。

### 2. 三大初始戰機核心選擇 (Ship Classes)
玩家於開局畫面可自由選擇三種不同戰術定位的機體：
1. **🚀 脈衝突擊者 (Striker)**：生命值 100，高射速、屬性均衡的全能型戰機。
2. **⚡ 幽靈疾風號 (Phantom)**：生命值 80，具備極高移動速度與高達 $30\%$ 的初始暴擊率。
3. **🛡️ 重裝泰坦號 (Bastion)**：生命值 150，高單發傷害，且開局自帶 **1 架環繞護衛機** 與 **1 層量子護盾**。

### 3. 主動戰術技能系統 (Active Tactical Skills)
* **⚡ 相位無敵衝刺 (`Space` 空白鍵)**：向移動方向瞬間位移並產生霓虹殘影粒子，期間享有短暫無敵幀（冷卻時間約 $1.8$ 秒）。
* **⏳ 時空緩速力場 (`Q` 鍵)**：展開駭客時間裂隙波紋，使全場所有敵機移動速度與敵方彈幕速度降低 $75\%$，持續 $4.5$ 秒（冷卻時間 $12$ 秒）。
* **💥 超新星爆發 (`E` 鍵)**：擊殺敵機可累積充能，達 $100\%$ 時可釋放全場震波，對大範圍內所有敵軍造成 $4.5$ 倍巨額傷害並清除危機。

### 4. Roguelite 升級卡牌系統 (9 大強化模組)
擊敗敵機拾取經驗寶石即可升級，每次升級系統將從 9 種模組中隨機抽取 3 張供玩家選擇（支援點擊或按鍵盤數字鍵 `1`、`2`、`3` 快速安裝）：
1. **多重プリズム射擊**：主武器每次發射額外 $+1$ 發光彈，擴大扇形彈幕覆蓋面。
2. **超頻脈衝核心**：射擊冷卻時間縮短 $20\%$，大幅提升每秒傷害輸出（DPS）。
3. **環繞雷射浮游機**：新增 $1$ 架環繞戰機旋轉的量子護衛機，自動切割靠近的敵機。
4. **相位穿透光束**：子彈穿透次數 $+1$，可直線貫穿密集的幾何敵群。
5. **高能電漿增幅**：基礎武器傷害提升 $+30\%$，暴擊率額外提升 $+8\%$。
6. **引力虹吸力場**：經驗寶石磁吸範圍擴大 $+55\%$、移動速度 $+12\%$，並立即回復 $35$ 點生命值。
7. **特斯拉連鎖閃電**：子彈命中時高機率觸發高壓電弧，自動在周圍敵機之間彈跳造成連鎖電擊。
8. **量子護盾發生器**：獲得 $+1$ 層可完全抵擋一次傷害的能量護盾（上限 $3$ 層），且最大生命值 $+25$。
9. **蜂群追蹤飛彈艙**：定期發射具備自動轉向導引能力的微型追蹤飛彈，精準鎖定遠處目標。

### 5. 幾何敵軍生態、空投補給與宇宙異象 (Enemies, Drops & Anomalies)
* **6 種幾何敵軍**：
  * `🔺 赤紅追獵者 (Chaser)`：基礎近戰追蹤敵機。
  * `🔸 黃金突襲機 (Dasher)`：體型小、高速逼近的突擊單位。
  * `💠 量子分裂體 (Splitter)`：被擊毀時會分裂成 $2$ 架高速迷你三角戰機。
  * `🎯 遠程狙擊艦 (Sniper)`：與玩家保持中距離走位，並定期發射暗橘色電漿彈幕。
  * `🟣 重裝六角艦 (Tank)`：高血量、高經驗值的重型裝甲單位。
  * `🛑 八角巨型首領艦 (Boss)`：每 $3$ 波登場一次，具備超高血量與 $6$ 向環狀彈幕攻擊。
* **4 種戰場隨機空投補給箱 (Supply Drops)**：
  * `💊 奈米修復`（回復 $40$ HP）、`🔥 狂暴超頻`（$6$ 秒內雙倍射速與移速提升）、`🧲 全域引力`（瞬間吸取全場所有經驗寶石）、`🛡️ 量子護盾`（護盾 $+1$）。
* **宇宙異象事件 — 🌀 黑洞引力奇點**：戰場定期生成旋轉紫色黑洞，自動將周圍非首領敵機強制牽引聚攏並造成持續絞碎傷害。

### 6. 視聽回饋與榮譽成就系統 (Visualizer & Achievements)
* **FEVER 連擊倍率**：連續擊殺敵人可累積連擊數，最高提供 $3\times$ 得分倍率加成。
* **底部即時霓虹音波頻譜**：畫布底部設有 28 道動態頻譜柱，會隨著背景音樂與武器射擊的音量能量即時跳動。
* **6 項星際榮譽成就**：包含「初陣告捷」、「霓虹律動大師 (25連擊)」、「時空駭客 (使用Q技能)」、「首領終結者」、「超頻武裝核心 (Lv.5)」與「星際傳奇生存者 (5000分)」，達成時於右下角彈出動態獎盃通知。

## 四、 Vibe Coding 與 AI 協作迭代紀錄 (Iterative Development Log)

本專案並非一次生成完畢，而是透過與 AI 進行三階段的「需求討論 ➔ 試玩回饋 ➔ 功能擴充與視覺打磨」反覆迭代而成：

### 🔹 第一階段：`v1.0` 基礎原型建立 (Core Prototype)
* **我方提出想法**：希望用單一 `index.html` 做出一款有霓虹科幻感、支援鍵盤與手機操作、且能切換視覺氛圍的生存射擊遊戲。
* **AI 實作成果**：建立 Canvas 遊戲迴圈、三大初始戰機選擇、3 種 Vibe 主題切換器、`Web Audio API` 基礎音效、6 種升級卡牌、無敵衝刺（`Space`）與超新星大招（`E`）。

### 🔹 第二階段：`v2.0` 戰術深度與敵軍多樣性擴充 (Tactical Expansion)
* **試玩觀察與迭代要求**：初版遊玩幾波後覺得敵人只會直線追擊略顯單調，且場上缺乏隨機驚喜與連擊爽快感，要求 AI 增加新敵人、場地道具與新武器。
* **AI 修改與完善**：
  1. 新增會發射彈幕的「遠程狙擊艦」與死亡會分裂的「量子分裂體」，並為 Boss 加上環狀彈幕。
  2. 新增 4 種「隨機空投補給箱」（補血、狂暴超頻、全域磁鐵、護盾）。
  3. 新增「特斯拉連鎖閃電」與「量子護盾發生器」兩張升級卡，以及頂部「Combo 連擊倍率系統」。
  4. 新增右上角「圖鑑視窗」，方便隨時查閱道具與敵機說明。

### 🔹 第三階段：`v3.0 Ultimate` 終極視聽律動與主動技能進化 (Ultimate Polish)
* **試玩觀察與迭代要求**：為了讓後期密集彈幕更有操作空間，並強化「Vibe Coding」的音樂視覺聯動與目標感，要求再加入控場技能、新飛彈、場地異象與成就系統。
* **AI 修改與完善**：
  1. 新增 `Q` 鍵主動技能 **「⏳ 時空緩速力場 (Bullet Time)」**，可減緩全場敵機與子彈速度 $75\%$。
  2. 新增會自動弧線轉向索敵的 **「🚀 蜂群追蹤飛彈艙」** 升級卡。
  3. 新增戰場隨機事件 **「🌀 黑洞引力奇點」**，能將敵群吸入中心聚怪。
  4. 於畫布底部加入 **「📊 即時霓虹音波頻譜」**，並實作 **「🏆 6 大星際成就即時解鎖通知與圖鑑紀錄」**。

## 五、 如何開啟與部署至 GitHub Pages (Deployment Guide)

### 1. 本地端直接開啟
* 下載本專案的 `index.html` 檔案，直接以任意現代瀏覽器（Chrome、Edge、Safari、Firefox）雙擊打開即可立即遊玩。

### 2. 部署至 GitHub Pages 步驟
1. 登入 GitHub，點擊右上角 `+` ➔ **New repository**。
2. 輸入儲存庫名稱（例如 `neon-vibe-survivor`），勾選 **Public**，點擊 **Create repository**。
3. 點擊 **uploading an existing file**，將 `index.html` 與本篇 `README.md` 拖曳上傳，並點擊 **Commit changes**。
4. 進入該 Repository 的 **Settings** ➔ 左側選單點擊 **Pages**。
5. 在 **Build and deployment** 下的 **Branch** 選擇 `main`（或 `master`）並點擊 **Save**。
